# منصة الرياضيات التفاعلية - الصف الأول المتوسط (الفصل الدراسي الأول)

تطبيق ويب تفاعلي ومسلي يهدف إلى تبسيط شروحات منهج الرياضيات للصف الأول المتوسط، مع التركيز على التفاعل، التقييم المستمر، وتثبيت المعلومات دون الحاجة لاتصال بالإنترنت.

---

## 🌟 مميزات التطبيق

* **شروحات تفاعلية ومسلية:** تبسيط المفاهيم الرياضية المعقدة بأسلوب شيق ومدعوم بأسئلة تفاعلية فورية.
* **اختبارات تقويمية شاملة:**
  * اختبارات مراجعة في نهاية كل فصل.
  * اختبار منتصف الفصل الدراسي الأول.
  * اختبار نهاية الفصل الدراسي الأول.
  * اختبار منتصف الفصل الدراسي الثاني.
  * اختبار شامل نهاية العام.
* **قسم خاص لتدريب جدول الضرب:** تمارين مخصصة لتقوية مهارات الحساب السريع.
* **يعمل بدون إنترنت (Offline-First):** يدعم التثبيت على الهواتف الذكية وأجهزة سطح المكتب للعمل بسلاسة في أي وقت ومن أي مكان.
